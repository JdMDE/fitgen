This repository contains the source code of the R package 'fitgen'.
Fitgen is mostly a set of C++ routines grouped in a library that fit many rows of a matrix to a model.
This routined are wrapped inside R code, with several R funcions added to facilitate its use and
improve functionality.

It can be installed from the sources, or simply from the R command line using the provided compressed file as

R CMD INSTALL fitgen_1.1.5.tar.gz

or similarly from RStudio.
